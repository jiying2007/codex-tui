# v1.4 Fuzzy Command Palette

Status: implementation

## Goal

Ctrl+K keeps the contextual command set captured when the palette opens, but
adds bounded bilingual fuzzy ranking instead of a fixed unfilterable list.

## Input contract

While the palette is open:

- ordinary printable characters append to the query;
- bracketed paste appends sanitized query text in one action;
- Backspace removes one query character;
- Up/Down move the result selection;
- Enter executes the selected result;
- Esc or Ctrl+K closes the palette.

The query is capped at 256 non-control characters. Arrow navigation does not
change the query.

When the ranked result list is empty, the overlay says so explicitly. Enter
does nothing and leaves the palette open; it cannot fall back to a stale or
hidden command.

## Ranking

Every command is matched against both English and Simplified Chinese palette
labels. Matching is a case-folded subsequence with ranking bonuses for:

- exact compact-label match;
- prefix match;
- matching at the beginning of a label;
- word/separator boundaries;
- contiguous matched characters.

Gaps and unrelated trailing label length reduce the score. Stable ties preserve
the frozen baseline command order.

The displayed label is the best-scoring language label for the current query.
Matched characters are rendered bold + underlined, without introducing a
color-only accessibility dependency.

An empty query preserves the original contextual order exactly.

## Context stability

Opening Ctrl+K freezes the eligible command vector. Background Registry/Git/
Forge updates cannot insert/remove/reorder that baseline while the palette is
open. Query filtering/ranking operates only over that frozen vector.

This preserves the existing guarantee that the highlighted command cannot
silently retarget because asynchronous state changed.

## Qualification

Retained tests cover:

- English and Chinese query matching;
- prefix/boundary ranking;
- matched-character positions used by the renderer;
- query length/control-character bounds;
- typed + pasted input;
- arrow navigation;
- empty result + Enter no-op;
- frozen baseline across context changes.
