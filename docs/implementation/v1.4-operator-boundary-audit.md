# v1.4 operator and asynchronous boundary audit

## Completed corrections in this audit series

- #226 replaces the unchecked final-byte duration split with checked UTF-8 slicing.
  Single and batch snooze reject invalid Unicode without losing editor state or
  creating write effects. This does not introduce natural-language duration syntax.
- #227 fences obsolete Git/Forge read results at consumption and retains full Forge
  review target identity. See `v1.4-read-boundaries.md` for the scope and limitations.
- Alias editing now freezes its thread ID at BeginAlias and resolves that ID against
  the live registry at commit. A removed target cannot silently retarget a replacement
  row. The input remains available with a bilingual refusal notice; cancellation
  clears the ephemeral target. A still-live target remains the intended recipient
  even when background filtering changes the selected row. No new persistent schema.

The alias regression uses the real reducer: removal and changed-filter cases fail
against the old numeric-index implementation; reorder and cancel are positive
controls. Full native regression must pass after the correction. Temporary audit
workflows/scripts and deliberate mutations are absent from the final source tree.

## Audited areas and retained boundaries

Operator input, asynchronous request/result identity, cache preservation, bounded
worker queues, offline recovery/WAL/forward-schema checks, release input coverage,
archive identity/layout, module limits and post-merge hygiene were reviewed alongside
existing regression coverage. Review selection and prompt acknowledgement fixes
are inherited, not reimplemented. Required migration/protocol adapters remain;
historical release checkpoints are not mislabeled as disposable branch residue.

The release path uses the final main identity, not a prior PR or an older duration
report. Native preview, development qualification and same-process structural soak
remain distinct evidence. GitHub-hosted tests and reported archive digests must not
be described as local recomputation. Exact run IDs and final SHA belong in the PR
receipts and external handoff #211 so no self-referential source commit is invented.

This bounded audit is not a proof of zero remaining bugs. Actual account/provider,
internal GitLab and Windows-SSH controlling-terminal qualification still require
real-environment evidence. Multi-hour leak freedom, power-loss atomic recovery,
remote exactly-once writes and end-to-end input-to-pixel SLO are not inferred from
synthetic tests. `stableReady=false`, `publicationAllowed=false`; no stable publish.
